## 🎯 Project Objective

The objective of this project is to analyze investment portfolio data and present key financial insights through interactive visualizations and performance indicators.

## 📌 Key Highlights

* Analyzed a portfolio of 180 investments.
* Evaluated total invested capital and current portfolio value.
* Analyzed total profit/loss and overall portfolio returns.
* Explored investment allocation across different asset classes.
* Compared investment performance by risk level and investment type.
* Used interactive filters to explore investment data.
